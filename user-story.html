User Story

Short, user-centred statements that describe a need and the value it delivers.

Purpose

User stories keep requirements focused on outcomes for real people. Classic format:

  • As a [role]
  • I want [capability]
  • So that [benefit]

Often accompanied by acceptance criteria, story points, and priority.

Workspace

Write and organise user stories, epics, and backlog notes here. Layout stays faithful to the parent page.
